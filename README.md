# KACH Hair Organic Solutions — интернет-магазин

Готовый сайт-магазин: главная, каталог с фильтрами, страницы товаров, корзина, оформление заказа, страница «О нас» с доставкой и контактами.

## Как посмотреть

Скачайте папку и откройте файл `index.html` двойным щелчком — сайт откроется в браузере. Ничего устанавливать не нужно.

## Где сайт в интернете

Сайт опубликован через GitHub Pages из ветки `gh-pages` на домене https://kachhair.com/

Файл `CNAME` (в нём `kachhair.com`) должен лежать в корне сайта: без него GitHub Pages отключит домен. Не удаляйте его и публикуйте в `gh-pages` всю ветку целиком, вместе с ним.

Чтобы обновить сайт, загрузите изменения в ветку `gh-pages`.

## Что где менять

| Что | Где |
|---|---|
| Товары, цены, описания | `js/products.js` (цена `null` = «Цена по запросу») |
| Фото товаров | `images/products/` (фото карточек), `images/posters/` (плакаты) |
| Телефон, почта, часы работы | `js/app.js`, блок `CONTACTS` в начале файла |
| Цвета сайта | `css/style.css`, в начале файла |
| Тексты на английском (основной язык) | `*.html`, `js/*.js`, `js/products.js` |
| Фиды товаров для Google Покупок (Merchant Center) | `feeds/google-*.xml`, создаются командой `node scripts/make-feeds.js` — запускайте после любой смены цен или товаров |
| Переводы: немецкий, итальянский, румынский, французский | `js/lang/de.js`, `it.js`, `ro.js`, `fr.js` (подключает `js/i18n.js`) |

## Важно про заказы

Сейчас заказ сохраняется только в браузере покупателя — вам он **не приходит**. Чтобы получать заказы на почту или в Telegram, нужно подключить сервис форм (например, Formspree) или онлайн-оплату. Это следующий шаг.

## Выручка по неделям (только для владельца)

Страница `revenue.html` (ссылки на неё на сайте нет). Войдите в кабинет под почтой владельца и откройте https://kachhair.com/revenue.html. Кто видит страницу — список почт в Supabase → Table Editor → `app_settings` → `admin_emails` (через запятую). С какой даты считать — `revenue_from`. Данные отдаёт функция базы `admin_paid_orders`.

## Онлайн-оплата (Stripe и PayPal)

- Серверная часть: `supabase/functions/payments/index.ts` (функция `payments` в Supabase).
- Ключи хранятся только в Supabase → Edge Functions → Secrets: `STRIPE_SECRET_KEY`, `PAYPAL_CLIENT_ID`, `PAYPAL_SECRET`, `PAYPAL_ENV` (`sandbox` или `live`), по желанию `STRIPE_WEBHOOK_SECRET`.
- Сумму к оплате сервер считает по таблице `product_prices` (евро). При изменении цен меняйте и `js/products.js`, и эту таблицу.
- Кнопки «Картой онлайн» и «PayPal» появляются, только если ключи заданы и у всех товаров в корзине есть цена.
