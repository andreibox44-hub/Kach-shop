# Kach — магазин натуральных шампуней

Готовый сайт-магазин: главная, каталог с фильтрами, страницы товаров, корзина, оформление заказа, страница «О нас» с доставкой и контактами.

## Как посмотреть

Скачайте папку и откройте файл `index.html` двойным щелчком — сайт откроется в браузере. Ничего устанавливать не нужно.

## Как опубликовать в интернете (бесплатно, GitHub Pages)

1. В репозитории на GitHub откройте **Settings → Pages**.
2. В поле **Branch** выберите ветку с сайтом и папку `/ (root)`, нажмите **Save**.
3. Через минуту сайт будет доступен по адресу `https://andreibox44-hub.github.io/kach-shop/`.

## Что где менять

| Что | Где |
|---|---|
| Товары, цены, описания | `js/products.js` |
| Телефон, почта, адрес | `about.html` и подвал в `js/app.js` |
| Стоимость доставки и порог бесплатной | `js/app.js`, в начале файла |
| Цвета сайта | `css/style.css`, в начале файла |
